# Tool reference — gemma-figma-mcp

Generated by `scripts/gen-tool-docs.mjs` from the server's registrations. Do not edit by hand.

88 tools. Optional parameters end with `?`. Colors are hex (`#0d99ff`, `#0d99ffcc`). Node ids look like `12:345`.

## Core: REST reads + plugin bridge

### `whoami`
User behind the configured token. Confirms the token works.
  (no parameters)

### `get_file`
Whole document as a compact outline (or raw JSON). Big files: pass depth, or use get_metadata then get_node.
  - `file_key?: string` — File key or Figma URL. Optional if FIGMA_DEFAULT_FILE_KEY is set.
  - `depth?: integer` — REST depth limit (1 = pages only, 2 = pages + top-level frames).
  - `format?: 'outline' | 'raw' = "outline"` — 'outline' = compact one-line-per-node text (default). 'raw' = full REST JSON (large).
  - `max_depth?: integer` — Outline only: deepest level to expand. Default 8.
  - `max_chars?: integer` — Cap on response characters. Default 20000.
  - `geometry?: 'paths'`
  - `branch_data?: boolean`

### `get_metadata`
Pages and top-level frames only (depth=2). Cheap overview; start here.
  - `file_key?: string` — File key or Figma URL. Optional if FIGMA_DEFAULT_FILE_KEY is set.
  - `format?: 'outline' | 'raw' = "outline"` — 'outline' = compact one-line-per-node text (default). 'raw' = full REST JSON (large).

### `get_node`
Subtree of one or more nodes as a compact outline (or raw JSON).
  - `file_key?: string` — File key or Figma URL. Optional if FIGMA_DEFAULT_FILE_KEY is set.
  - `node_ids: string[]` — Node ids like '12:34'.
  - `format?: 'outline' | 'raw' = "outline"` — 'outline' = compact one-line-per-node text (default). 'raw' = full REST JSON (large).
  - `max_depth?: integer` — Outline only: deepest level to expand. Default 8.
  - `max_chars?: integer` — Cap on response characters. Default 20000.

### `get_components`
Components defined in the file (key, name, description).
  - `file_key?: string` — File key or Figma URL. Optional if FIGMA_DEFAULT_FILE_KEY is set.

### `get_styles`
Paint/text/effect/grid styles defined in the file.
  - `file_key?: string` — File key or Figma URL. Optional if FIGMA_DEFAULT_FILE_KEY is set.

### `get_comments`
All comments on the file.
  - `file_key?: string` — File key or Figma URL. Optional if FIGMA_DEFAULT_FILE_KEY is set.
  - `as_md?: boolean`

### `post_comment`
Add a comment; comment_id makes it a reply.
  - `file_key?: string` — File key or Figma URL. Optional if FIGMA_DEFAULT_FILE_KEY is set.
  - `message: string`
  - `comment_id?: string`

### `get_image`
Figma-rendered PNG/JPG/SVG/PDF of nodes via REST. Returns temporary URLs, no image inline. Prefer get_screenshot when the plugin is connected.
  - `file_key?: string` — File key or Figma URL. Optional if FIGMA_DEFAULT_FILE_KEY is set.
  - `node_ids: string[]`
  - `format?: 'jpg' | 'png' | 'svg' | 'pdf' = "png"`
  - `scale?: number`
  - `svg_include_id?: boolean`
  - `svg_simplify_stroke?: boolean`
  - `use_absolute_bounds?: boolean`
  - `version?: string`

### `bridge_status`
Connection check: daemon, plugin, open file, current page. Use once per session or after a canvas tool fails; other tools do not need it first.
  (no parameters)

### `use_figma`
Run Plugin API JavaScript in the open Figma file. Body of an async function; `figma`, `selection`, `currentPage` plus helpers query(root, sel), set(node, props), createAutoLayout(dir, props), loadFontsFor(node), hex(c), solid(c) in scope. `return` a small object. Response adds created_ids/changed_ids.
  - `code: string`
  - `screenshot?: boolean` — Also return a PNG of the top-level nodes the snippet created.
  - `timeout_ms?: integer` — Default 30000.

### `get_selection`
Summary of the nodes selected in Figma right now.
  (no parameters)

### `get_current_page`
Active page (id, name, child count) and current selection.
  (no parameters)

### `get_screenshot`
Render nodes via the plugin: saves to ./screenshots and returns the image inline. Omit node_ids for the selection. If pixels are unchanged since the last call, says so and sends no image.
  - `node_ids?: string[]`
  - `format?: 'PNG' | 'JPG' | 'SVG' = "PNG"`
  - `scale?: number = 1`
  - `max_px?: integer = 1024` — Longest side cap in px; scale is lowered to fit.

## Canvas helpers (plugin)

### `create_frame`
Empty frame at x,y with width/height.
  - `x: number`
  - `y: number`
  - `width: number`
  - `height: number`
  - `name?: string`
  - `parent_id?: string` — Parent node id; default: current page.

### `create_rectangle`
Rectangle with optional solid fill.
  - `x: number`
  - `y: number`
  - `width: number`
  - `height: number`
  - `fill?: string` — Hex, e.g. #0d99ff or #0d99ffcc (alpha).
  - `name?: string`
  - `parent_id?: string` — Parent node id; default: current page.

### `create_ellipse`
Ellipse/circle with optional solid fill.
  - `x: number`
  - `y: number`
  - `width: number`
  - `height: number`
  - `fill?: string` — Hex, e.g. #0d99ff or #0d99ffcc (alpha).
  - `name?: string`
  - `parent_id?: string` — Parent node id; default: current page.

### `create_text`
Text node. Loads the font first (default Inter Regular; falls back to it if the font is missing).
  - `x: number`
  - `y: number`
  - `content: string`
  - `font_size?: number`
  - `font_family?: string`
  - `font_style?: string` — Regular | Bold | Medium | ... Default Regular.
  - `color?: string` — Hex, e.g. #0d99ff or #0d99ffcc (alpha).
  - `name?: string`
  - `parent_id?: string` — Parent node id; default: current page.

### `create_line`
Line from (x1,y1) to (x2,y2).
  - `x1: number`
  - `y1: number`
  - `x2: number`
  - `y2: number`
  - `stroke?: string` — Hex, e.g. #0d99ff or #0d99ffcc (alpha).
  - `stroke_weight?: number`
  - `name?: string`
  - `parent_id?: string` — Parent node id; default: current page.

### `clone_node`
Duplicate a node, offset 20px.
  - `node_id: string` — Node id, e.g. 12:345.

### `move_node`
Set absolute x/y.
  - `node_id: string` — Node id, e.g. 12:345.
  - `x: number`
  - `y: number`

### `resize_node`
Set width/height.
  - `node_id: string` — Node id, e.g. 12:345.
  - `width: number`
  - `height: number`

### `set_fill`
Replace fills with one solid color.
  - `node_id: string` — Node id, e.g. 12:345.
  - `color: string` — Hex, e.g. #0d99ff or #0d99ffcc (alpha).
  - `opacity?: number` — 0-1; overrides the hex alpha.

### `set_stroke`
Replace strokes with one solid color; optional weight.
  - `node_id: string` — Node id, e.g. 12:345.
  - `color: string` — Hex, e.g. #0d99ff or #0d99ffcc (alpha).
  - `weight?: number`

### `set_text`
Replaces the characters of a text node, loading its current font first.
  - `node_id: string` — Node id, e.g. 12:345.
  - `content: string`

### `rename_node`
Sets the name of a node.
  - `node_id: string` — Node id, e.g. 12:345.
  - `name: string`

### `delete_nodes`
Removes one or more nodes by id. Missing ids are reported in 'skipped'.
  - `node_ids: string[]`

### `set_selection`
Selects the given node ids on the current page.
  - `node_ids: string[]`

### `find_nodes`
Find nodes on the current page. For 'all text layers' / 'all frames' pass only `type`; pass `name_pattern` only when a name is known. Returns id, name, type.
  - `name_pattern?: string` — Case-insensitive regex on the name. Omit to match any name (never pass '.*').
  - `type?: 'TEXT' | 'FRAME' | 'RECTANGLE' | 'ELLIPSE' | 'LINE' | 'VECTOR' | 'INSTANCE' | 'COMPONENT' | 'COMPONENT_SET' | 'GROUP' | 'SECTION' | 'BOOLEAN_OPERATION' | 'POLYGON' | 'STAR' | 'SLICE'` — Node type filter.
  - `limit?: integer = 50`

### `group_nodes`
Wraps the given nodes into a Figma group inside their shared parent.
  - `node_ids: string[]`
  - `name?: string`

### `set_auto_layout`
Enable/update auto-layout on a frame; direction NONE disables.
  - `node_id: string` — Node id, e.g. 12:345.
  - `direction: 'HORIZONTAL' | 'VERTICAL' | 'NONE'`
  - `item_spacing?: number`
  - `padding?: number` — Uniform padding.

  - `node_id?: string` — Default: current selection.
  - `max_depth?: integer = 8`
  - `max_nodes?: integer = 300`

## Components & instances (plugin)

### `list_components`
Components and component sets in the open file (current page by default; scope=file loads every page). Returns id, name, key, variants.
  - `scope?: 'page' | 'file' = "page"`
  - `name_pattern?: string` — Case-insensitive regex on the name.
  - `limit?: integer = 100`

### `create_instance`
Place an instance of a component: by library key (component_key from get_components / search_design_system) or by node id of a component/component set in this file.
  - `component_key?: string`
  - `component_id?: string`
  - `x: number`
  - `y: number`
  - `name?: string`
  - `parent_id?: string` — Parent node id; default: current page.
  - `properties?: object` — Component properties to set, e.g. { State: 'Hover', Label: 'Send' }.

### `get_instance_properties`
Main component, current component properties and the definitions (variant options, defaults) an instance accepts.
  - `node_id: string` — Node id, e.g. 12:345.

### `set_instance_properties`
Set variant / boolean / text / instance-swap properties on an instance. Use the keys from get_instance_properties (text and boolean keys end with #id).
  - `node_id: string` — Node id, e.g. 12:345.
  - `properties: object`

### `swap_instance`
Point an instance at another component (library key or node id). Overrides are kept where names match.
  - `node_id: string` — Node id, e.g. 12:345.
  - `component_key?: string`
  - `component_id?: string`

### `create_component`
Turn a frame/group into a COMPONENT (in place). Optional name and description.
  - `node_id: string` — Node id, e.g. 12:345.
  - `name?: string`
  - `description?: string`

### `combine_as_variants`
Combine COMPONENT nodes into one COMPONENT_SET. Name each component 'Prop=Value, Prop2=Value' first so variants get properties.
  - `node_ids: string[]`
  - `name?: string`

### `detach_instance`
Detach an instance into a plain frame (keeps its look, loses the link).
  - `node_id: string` — Node id, e.g. 12:345.

## Variables (plugin)

### `list_variable_collections`
Local variable collections in the open file with their modes and variable counts.
  (no parameters)

### `list_variables`
Local variables with values per mode (colors as hex, aliases as {alias}). Filter by collection and/or type.
  - `collection_id?: string`
  - `type?: 'COLOR' | 'FLOAT' | 'STRING' | 'BOOLEAN'`
  - `name_pattern?: string` — Case-insensitive regex on the name.
  - `limit?: integer = 200`

### `create_variable_collection`
New local collection. modes renames the default mode and adds the rest (e.g. ['Light', 'Dark']).
  - `name: string`
  - `modes?: string[]`

### `create_variable`
New local variable in a collection. value applies to every mode unless values_by_mode is given (mode name -> value). Colors as hex; aliases as 'VariableID:...'.
  - `collection_id: string`
  - `name: string` — Use slashes for groups: 'color/brand/primary'.
  - `type: 'COLOR' | 'FLOAT' | 'STRING' | 'BOOLEAN'`
  - `value?: string,number,boolean`
  - `values_by_mode?: object`
  - `scopes?: string[]` — COLOR: FRAME_FILL, SHAPE_FILL, TEXT_FILL, STROKE_COLOR, EFFECT_COLOR, ALL_FILLS. FLOAT: GAP, WIDTH_HEIGHT, CORNER_RADIUS, OPACITY, STROKE_FLOAT, EFFECT_FLOAT, FONT_SIZE, LINE_HEIGHT, LETTER_SPACING. Default: sensible per type.
  - `description?: string`

### `set_variable_value`
Set a variable's value for one mode (default mode if omitted). Colors as hex; 'VariableID:...' creates an alias.
  - `variable_id: string`
  - `value: string,number,boolean`
  - `mode?: string` — Mode name or id.

### `bind_variable`
Bind a variable to fill, stroke, width, height, opacity, cornerRadius (all corners), padding (all sides), itemSpacing, characters, visible, strokeWeight, minWidth/maxWidth/minHeight/maxHeight, or any VariableBindableNodeField.
  - `node_id: string` — Node id, e.g. 12:345.
  - `field: string`
  - `variable_id: string`

### `get_variable_defs`
Every variable bound in a node's subtree (or the selection): which node and property, variable name, collection, resolved value. Also lists style names in use.
  - `node_id?: string`
  - `max_nodes?: integer = 1000`

Download a team's published components, component sets and styles into a local cache (.cache/design-system-<team>.json). Re-run to refresh.
  - `team_id: string` — Team id from figma.com/files/team/<TEAM_ID>/...
  - `page_size?: integer = 30` — Per-call page size; max 1000.

### `search_design_system`
Fuzzy search the local design-system cache by name/description.
  - `query: string`
  - `team_id?: string` — Limit to one team; default all cached.
  - `type?: 'component' | 'component_set' | 'style'` — Filter by item kind.
  - `limit?: integer = 20`

### `clear_design_system_cache`
Deletes design-system-*.json cache files. Pass team_id to clear one team; omit to clear all.
  - `team_id?: string`

## Filesystem workspaces

### `register_workspace`
Register an absolute, existing directory as a named workspace the model may read/write.
  - `name: string` — Short name: letters, digits, _ or -.
  - `path: string` — Absolute filesystem path.
  - `description?: string`
  - `force?: boolean = false` — Allow system folders.

### `unregister_workspace`
Removes a workspace from the registry. Files on disk are NOT touched.
  - `name: string` — Workspace name (list_workspaces).

### `list_workspaces`
Returns all workspaces along with their on-disk status.
  (no parameters)

### `list_dir`
Lists files and folders under workspace/path.
  - `workspace: string` — Workspace name (list_workspaces).
  - `path?: string` — Path relative to the workspace root; '' = root.

### `read_text_file`
Read a workspace file as text.
  - `workspace: string` — Workspace name (list_workspaces).
  - `path: string` — Path relative to the workspace root; '' = root.
  - `encoding?: 'utf8' | 'utf16le' | 'latin1' | 'ascii' = "utf8"`
  - `max_bytes?: integer = 1000000` — Size limit; default 1 MB.

### `read_binary_file`
Read a workspace file as base64.
  - `workspace: string` — Workspace name (list_workspaces).
  - `path: string` — Path relative to the workspace root; '' = root.
  - `max_bytes?: integer = 5000000`

### `write_text_file`
Write a text file (creates parent dirs). Refuses to overwrite unless overwrite=true.
  - `workspace: string` — Workspace name (list_workspaces).
  - `path: string` — Path relative to the workspace root; '' = root.
  - `content: string`
  - `overwrite?: boolean = false`
  - `encoding?: 'utf8' | 'utf16le' | 'latin1' | 'ascii' = "utf8"`

### `make_dir`
Creates a directory (including parents) inside a workspace.
  - `workspace: string` — Workspace name (list_workspaces).
  - `path: string` — Path relative to the workspace root; '' = root.

### `move_path`
Rename/move within the same workspace.
  - `workspace: string` — Workspace name (list_workspaces).
  - `from: string` — Path relative to the workspace root; '' = root.
  - `to: any`
  - `overwrite?: boolean = false`

### `delete_path`
Delete a file or directory (recursive=true for non-empty).
  - `workspace: string` — Workspace name (list_workspaces).
  - `path: string` — Path relative to the workspace root; '' = root.
  - `recursive?: boolean = false`

### `import_image_to_figma`
Place a PNG/JPG/GIF/WEBP from a workspace on the canvas as a rectangle with an image fill (natural size unless width/height given).
  - `workspace: string` — Workspace name (list_workspaces).
  - `path: string` — Path relative to the workspace root; '' = root.
  - `x: number`
  - `y: number`
  - `width?: number`
  - `height?: number`
  - `name?: string`
  - `parent_id?: string` — Optional Figma parent node id.
  - `fit?: 'FILL' | 'FIT' | 'CROP' | 'TILE' = "FILL"`
  - `max_bytes?: integer = 10000000`

## Code Connect

### `scan_code_connect`
Walks a directory looking for *.figma.ts(x) / *.figma.js(x) and returns each figma.connect() call with its target file key and node id.
  - `directory?: string` — Absolute directory to scan. Default is the MCP server's working directory.
  - `max_files?: integer = 500`

### `read_code_connect`
Returns the contents of a single *.figma.ts(x) / *.figma.js(x) file plus parsed connection metadata.
  - `file_path: string`

### `find_node_mapping`
Scans a project for any *.figma.ts(x) file connected to the given Figma node.
  - `file_key?: string` — Figma file key or full URL. Optional if FIGMA_DEFAULT_FILE_KEY is set.
  - `node_id: string`
  - `directory?: string` — Project directory to scan. Default: cwd.

### `get_node_props_for_connect`
Returns the componentPropertyDefinitions of a Figma component or component set, simplified for use in Code Connect templates.
  - `file_key?: string`
  - `node_id: string`

### `generate_code_connect`
Generate a *.figma.ts template (React/Vue/HTML) from the node's component properties.
  - `file_key?: string`
  - `node_id: string`
  - `framework: 'react' | 'vue' | 'html'`
  - `component_name?: string` — Component name for import + figma.connect; default: node name.
  - `component_import?: string` — Custom import line; overrides the generated one.

### `save_code_connect`
Writes a *.figma.ts(x) file to disk. By default refuses to overwrite an existing file — pass overwrite=true to replace it.
  - `file_path: string`
  - `content: string`
  - `overwrite?: boolean = false`

### `publish_code_connect`
Run `npx @figma/code-connect connect publish` in the directory (token forwarded as FIGMA_ACCESS_TOKEN). dry_run previews.
  - `directory?: string` — Directory with *.figma.ts(x) and figma.config.json; default cwd.
  - `dry_run?: boolean = false`

## Help

### `help`
Returns a concise guide for this MCP server. Call without args for the index, or pass a topic ('overview', 'canvas', 'rest', 'examples', 'troubleshoot').
  - `topic?: 'overview' | 'canvas' | 'rest' | 'code-connect' | 'design-system' | 'diagrams' | 'figjam' | 'filesystem' | 'examples' | 'troubleshoot'` — Topic to fetch. Omit to get the index of available topics.
